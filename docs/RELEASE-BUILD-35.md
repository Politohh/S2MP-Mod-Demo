# S2MP Mod v1.0.2 (Build 35)

FFmpeg is now included for ProRes recording. No separate FFmpeg download or setup is needed. The camera and demo tools are unchanged, `dolly_slow_clock` stays off by default, and the `com_maxfps` limit is 1000.

## Install and launch

1. Download **S2MP-Mod-v1.0.2-build-35.zip** below and extract it.
2. Close Call of Duty: WWII. Drag the extracted files and folders into your WWII game folder, next to `s2_mp64_ship.exe`. Replace older copies when asked.
3. Run **S2MP-Launcher.exe** and click **Multiplayer**.
4. Press **F9** or **Insert** to open the tools menu. **F1** opens the timeline.

Open the **Recording** tab to choose your ProRes settings. **F5** starts or stops recording. The included `ffmpeg.exe` is detected automatically.

You need your own copy of WWII. ReShade is optional and installed separately; see `RESHADE-SETUP.txt` if you want its effects in recordings.

FFmpeg's license, source, and build details are included in the `FFmpeg` folder. Keep that folder with the package when sharing it.
