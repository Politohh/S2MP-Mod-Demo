# S2MP Mod v1.0.4 (Build 37)

## Install

1. Close Call of Duty: WWII.
2. Copy all the extracted files and folders into your WWII game folder, next to `s2_mp64_ship.exe`. Replace older copies when asked.
3. Run **S2MP-Launcher.exe** and click **Multiplayer**.

**F9** or **Insert** opens the tools menu. **F1** opens the demo timeline.

FFmpeg is included and detected automatically. Choose your ProRes settings in the **Recording** tab; **F5** starts or stops recording.

You need your own copy of WWII. ReShade is optional and installed separately; see [RESHADE-SETUP.txt](RESHADE-SETUP.txt) to capture its effects.

See [CREDITS.md](CREDITS.md) for the original developers and [FFmpeg/README.txt](FFmpeg/README.txt) for FFmpeg's license and source. Keep the included notices and source when sharing this package.
