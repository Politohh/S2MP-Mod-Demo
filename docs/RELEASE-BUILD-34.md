# S2MP Mod v1.0.1 (Build 34)

`com_maxfps` now accepts 0–1000 in the console. The FPS control uses the same range. This build keeps the v1.0 cinematic tools and `dolly_slow_clock 0` by default.

## Install and launch

1. Download `S2MP-Mod-v1.0.1-build-34.zip` below and extract it.
2. Close Call of Duty: WWII. Copy **both** `S2MP-Launcher.exe` and `s2mp-mod.dll` into your WWII game folder, next to `s2_mp64_ship.exe`. Replace the older copies if you have them.
3. Run `S2MP-Launcher.exe` and click **Multiplayer**.
4. Press **F9** or **Insert** to open the tools menu. **F1** opens the timeline.

The game itself is not included in the download.
