# S2MP Mod v1.0.7 (Build 40)

J now selects the free camera before seeking to the first dolly point and restores that camera mode after an in-place seek. Stopping a demo closes the tools menu so its input capture is released when WWII returns to the menu. The final camera-roll hook now covers custom demos as well as native demos.

Also includes the config-loading and map-cleanup changes since the previous public release, Build 35. FFmpeg is bundled for ProRes recording.

## Install and launch

Close WWII and copy all extracted files and folders into the game folder, beside `s2_mp64_ship.exe`. Replace older copies. Run **S2MP-Launcher.exe** and click **Multiplayer**. **F9** or **Insert** opens the tools menu.
